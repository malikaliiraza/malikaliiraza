Bus Ticket Reservation System

A menu-driven bus ticket reservation system in C++ with separate Admin and Booking interfaces. It renders a 10-seat booking layout with live seat status, tracks seat availability, and applies tiered fare discounts for students, faculty, and staff.

Overview

  • Separate Admin and Booking interfaces in one menu-driven console app
  • 10-seat booking layout with live seat status and seat availability tracking
  • Tiered fare discounts for students, faculty, and staff
  • Fare calculation based on distance, with booking confirmation
  • Input validation for robust console interaction
  • Built with functions, arrays, loops, conditional statements, and structures (struct) for data organization
  • Built in Microsoft Visual Studio
