Personal Finance Manager

A console-based personal finance management system in C++ that applies object-oriented programming principles: it tracks income, expenses, and account balance, schedules meetings, and generates daily and monthly financial reports – built around an abstract Record base class with Transaction and Meeting subclasses exercising inheritance and polymorphism.

View repo on GitHub

// SCREENSHOTS

Overview

  • Password-protected user authentication
  • Income and expense tracking with balance validation that prevents overspending by validating the available balance
  • Transaction history with daily and monthly report generation
  • Meeting scheduling built on the same Record class hierarchy
  • Automatic profit and loss calculation
  • Modular class-based architecture: an abstract Record base class with Transaction / Meeting subclasses, exercising inheritance and polymorphism
  • Data managed with STL vector and map containers
  • Built in Microsoft Visual Studio
