// PROJECT — SCRATCH GAME

Apex Dash

A fast-paced, rhythm-based obstacle-dodging game built in Scratch 3.0. Guide your character through an auto-scrolling world, timing jumps to clear obstacles and rack up the highest score – a beginner-friendly arcade game that teaches event-driven programming, timing-based game logic, and interactive score tracking.

View repo on GitHub

// SCREENSHOTS

Overview

  • Guide your character through an auto-scrolling world, timing jumps to clear obstacles and chase the highest score
  • Jump mechanic with a rise/fall arc; auto-scrolling level with adjustable scroll speed
  • Real-time obstacle collision detection and real-time score tracking
  • Background music and sound effects, with custom sprites and backdrops
  • Built with block-based programming: variables, loops (forever, repeat), event handling (when key pressed, when flag clicked), collision detection, timing-based game logic, score tracking, and animation
  • Controls: Space = jump, Green Flag = start game
  • To run it: download the repository, open apex-dash.sb3 in Scratch Desktop, Scratch Online, or TurboWarp, click the Green Flag, and press Space to jump

Tech stack

Scratch 3.0Block-Based ProgrammingEvent-Driven Logic
